# BugMeme

**Gerador de memes de tech que não funciona** — e agora reage ao caos.

Um brinquedo viral que cria desculpas de programador + respostas de IA em loop + situações absurdas. Com animações reativas ao status, exportação de GIF, figurinhas de WhatsApp e muito vaporwave glitch.

## Blueprint

O documento completo de produto, arquitetura e roadmap está em [`BLUEPRINT.md`](./BLUEPRINT.md).

## Stack prevista

- Next.js + React + Tailwind + Framer Motion
- PostgreSQL (Neon / Supabase)
- Auth (Clerk ou NextAuth)
- Deploy na Vercel

## Roadmap resumido

- **MVP**: Gerador com status reativo + animações + download de imagem/GIF + compartilhamento + auth básica
- **v1.0**: Figurinhas animadas, galeria, curadoria, wallpaper animado
- **Futuro**: Premium, sticker packs, comunidade
